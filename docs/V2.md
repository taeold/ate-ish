# ate-ish v2: substrate's worker, our control plane

Decisions (2026-10-29; goal restated 2026-10-29 by the user: the easiest way to test-drive and deploy actors with Agent Substrate compatibility, one command to Cloud Run). ate-ish becomes the easiest way to try Agent
Substrate: one binary, the substrate YAMLs as input, workload compatibility
by running substrate's own gVisor worker. Local first. Two or three nodes
over one bucket, celld style. Cloud Run gen2 is one place to run a node.
No promises in the README.

## What is reused, unmodified

From agent-substrate/substrate (Apache-2.0; vendor copies under
third_party/ with the LICENSE, do not edit them):

- cmd/ateworker-gvisor: the worker. gRPC service `Worker` in
  internal/proto/ateworkerpb: RunWorkload, CheckpointWorkload,
  RestoreWorkload, TerminateWorkload, GetWorkloadStats,
  GetActiveWorkloadStats. Per actor it takes runsc_path, WorkloadSpec,
  ActorDirs (root_dir, oci_bundle_dir, checkpoint_dir, restore_dir,
  durable_dir_volume_mounts_dir, system_info_volume_roots_dir,
  external_volume_mounts_dir, sandbox_assets_dir), resources, optional
  EgressGateway{address}.
- internal/ateworker/actornet (veth + nftables + DNS relay + atunnel),
  internal/ocispec (bundle config.json from a WorkloadSpec),
  internal/volume (durable dirs), and whatever internal packages those
  import. internal/proto/ateworkerpb and its generated code.
- pkg/objectstorage for snapshot blobs (GCS; S3 exists there for later).
- runsc from a gVisor release (GitHub release asset
  gvisor-x86_64.tar.zstd), pinned by version.

Not reused: ateapi, atelet, atecontroller, atenet, Postgres, OpenFGA,
pod certificates, Envoy, image cache.

## What ate-ish keeps

The bucket control plane from v1 (records with conditional writes,
leases, ingress with placement and parking, tags, fork, CLI verbs), the
README structure, the demos under demo/.

## What changes

- worker.go and sandbox.go: the launcher calls become a small atelet:
  build ActorDirs and the OCI bundle for the template (rootfs is the
  node's own filesystem through runsc's overlay, as v1 did), call the six
  RPCs on ateworker-gvisor over a unix socket, move checkpoint_dir to and
  from the store, report the actor's address (its veth address and
  container port; port 80 works now).
- egress: the worker's proxy is the EgressGateway address. Confirm what
  atunnel presents on its CONNECT and accept it. Enforcement is now the
  sandbox's network, not convention; the README's limits section changes
  accordingly.
- store: one interface, four methods: get (value, version), put if
  version matches (version 0 = create), delete, list prefix. One
  implementation now: GCS with ifGenerationMatch (refactor bucket.go).
  A local-directory implementation only if it is under 100 lines
  (atomic rename + a version file); otherwise later. S3 later.
- fidelity: templates asking for MEMORY get a runsc checkpoint; VOLUMES
  gets the durable dirs only, as the worker already distinguishes.
- node address: a lease carries the address other nodes reach this node
  on (a flag; the VPC IP from the metadata server on Cloud Run; a LAN IP
  locally). Any node accepts ingress.

## Host requirements (state them, do not hide them)

Linux, root or the capability set substrate's worker pool declares
(NET_ADMIN, SYS_ADMIN, SYS_CHROOT, SYS_PTRACE, NET_RAW, DAC_OVERRIDE,
FOWNER, CHOWN, MKNOD), nftables in the kernel, runsc on the systrap
platform (no KVM needed). Cloud Run gen2 gives root all of these except
MKNOD today, undocumented.

## Stages and gates

Stop at the first gate that fails; write the exact error and stop.

0. Local probe, no ate-ish code. On this VM (passwordless sudo, kernel
   6.12, nft and ip present): build ateworker-gvisor from the substrate
   clone, fetch runsc, run the worker as root with a unix socket, drive
   RunWorkload by hand (a small Go or grpcurl client) with a WorkloadSpec
   for the pi-durable demo image's rootfs or for busybox httpd, the
   ActorDirs laid out under /tmp/ate-ish-probe. Gate: the actor answers
   HTTP on its veth address; from inside the actor, a connection to an
   arbitrary internet host is refused or dropped while a connection
   through the gateway address works; CheckpointWorkload then
   RestoreWorkload brings the actor back with its state (a file it wrote
   and, for MEMORY, a counter in process memory). Record timings. Record
   what atunnel sends on its CONNECT.
1. Vendor. Copy the packages into ate-ish/third_party with LICENSE and a
   VENDOR.md naming the upstream commit. ate-ish builds with them. No
   edits to vendored files; if one is needed, record it in VENDOR.md as a
   patch.
2. The small atelet. worker.go drives the vendored worker. Gate: the v1
   gate.sh play sequence passes on ONE local node with the local store or
   a GCS bucket (pi-durable on the Gateway variant; the Gemini key in
   daniel-junk is revoked), including suspend, tag, fork.
3. Egress through the worker's network. Gate: the egress check in gate.sh
   now asserts that the unproxied fetch to an unlisted host FAILS (the
   opposite of v1), and the proxied fetch with the placeholder key gets
   the model's answer.
4. Two nodes. Two ate-ish processes on this VM with different ports and
   addresses, one bucket. Gate: an actor created through node A, suspended,
   resumed through node B on node B, with its files; parking across both.
5. Cloud Run. One gen2 instance running the same binary (role all). Gate:
   gate.sh play. If runsc cannot start there, record the error; the local
   result stands.
6. Demo table. Re-run the three coding-agents demos and the substrate
   counter demo (file counter and in-memory counter) locally; update the
   README's pass/fail table and the limits section; push.

7. One command. `ate-ish deploy -f template.yaml [-e egress-policy.yaml]`
   from a directory holding the actor's Dockerfile: builds the actor
   image FROM the user's Dockerfile with the ate-ish binary and runsc
   added, pushes it, creates the bucket and the Cloud Run gen2 instance
   if missing, uploads the template and the egress policy, and prints the
   URL and the curl line. Gate: a fresh clone of
   coding-agents-on-substrate/pi-durable (its own Dockerfile, its own
   template.yaml and egress-policy.yaml, listen on 80 unchanged) is
   running on Cloud Run after one command and answers a turn through the
   actor header. That is the hook: "write an Agent Substrate actor,
   deploy it to Cloud Run in one command."

8. Local dev, the primary target (see docs/WHAT.md). `ate-ish dev` run
   from an actor's directory: a local-directory implementation of the
   store (atomic rename + version file, under ./.ate-ish/dev, `--clean`
   wipes it), the actor rootfs exported once from the template's image
   (docker export or crane export into the dev directory; locally the
   host filesystem is no longer the rootfs), runsc fetched if missing,
   one node started with the local store, the template and egress policy
   uploaded from the current directory, one actor created, the curl line
   printed. Two ways to run it: `sudo ate-ish dev` on Linux, or
   `docker run --privileged -v "$PWD":/work -p 8080:8080 <image> dev`
   where the image is the ate-ish base image (works on macOS through
   Docker Desktop). Gate: from a fresh clone of
   coding-agents-on-substrate/pi-durable, with its files unchanged except
   the model key, `docker run --privileged ... dev` then the printed curl
   answers a turn; the same with `sudo ate-ish dev`; the kubectl-ate verbs
   (`ate-ish get actors`, `suspend`, `create tag`, fork) work against it;
   Node must NOT be installed on the host for the Docker path to pass.
   README quickstart becomes the local one; Cloud Run moves to its own
   section with its limits.

## Cost rules

Implementation runs on a cheaper model. One stage per message; the
same agent is resumed for the next stage so it keeps context. The agent
writes docs/PROGRESS.md as it goes and ends each stage with a report
under 25 lines: gate result, numbers, files changed, blockers. No
independent review subagents unless asked. Cloud spend only in stage 5
and the demo re-runs; everything else is local.
